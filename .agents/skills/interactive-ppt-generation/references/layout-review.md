# 页面文字与图文布局验收规范

在 Stage 8 编写逐页施工图、Stage 9 生成 SVG 和 Stage 10 发布 PPTX 时读取本文。它负责防止文字溢出、文字进入图片、段落粘连和转换后的重新换行。

## 1. 结构化文字对象

不得把整页文字或整篇讲稿放进一个 `<text>` 元素。将页面文字拆成可独立定位的对象：

| 对象 | 处理 |
|---|---|
| 标题、副标题 | 各自独立文本对象 |
| 正文段落 | 每个语义段落独立对象；段内明确分行 |
| 要点 | 每条要点独立，或使用结构清晰的段落组 |
| 图注、标签、来源 | 与正文分离，使用独立边界和字号 |

完整讲稿只保存在 `narrative/speaker-notes.md`。`slide-copy.md` 只保存观众必须看到的精简文字。

---

## 2. 施工图文字约束

`production/slide-production-plan.md` 为每个文字对象记录：

| 字段 | 要求 |
|---|---|
| 内容键 | 指向 `slide-copy.md` 中的唯一对象 |
| `x, y, w, h` | 明确文字安全区域 |
| 字体参数 | 字体、字号、字重、颜色、行距和段间距 |
| 容量 | 预计行数与最大行数 |
| 对齐 | 水平和垂直对齐方式 |
| 邻接关系 | 与图片、图形和其他文字的最小间距 |

为图片和文字分别划定区域。除非施工图明确声明“文字覆盖图片”并提供可读性底板、渐变或遮罩，否则两类区域不得相交。

---

## 3. SVG 实现约束

- 使用根级语义 `<g>` 组织页面模块，并用 `data-pptx-bounds="x y w h"` 声明模块安全区。
- 将每个文字对象放入其所属模块；文字估算边界必须落在模块安全区内。
- 不依赖浏览器自动换行；用独立 `<text>` 或受控 `tspan` 明确每行位置。
- 为段落保留可见段间距，不用连续空格或超长单行模拟排版。
- 图片裁剪框、图注和来源框各自独立，不把图注写进图片区域。

---

## 4. 三次验收

| 时机 | 检查 |
|---|---|
| 施工图完成后 | 坐标矩形不发生非预期相交，行数与文字容量匹配 |
| SVG 生成后 | 运行 Checker，渲染整页预览，检查溢出、遮挡、段落和对齐 |
| PPTX 发布后 | 按 `latest.json` 精确路径打开或渲染，复查转换后的换行和图片位置 |

Checker 能估算文字是否越出 `data-pptx-bounds`，但不能替代视觉检查所有图文碰撞。每页结果写入 `production/layout-review.md`。

---

## 5. 修复顺序

发现文字超出、进入图片或无法分段时，按顺序修复：

```text
精简上屏文字
→ 按语义重新分段和换行
→ 扩大文字区域或调整图文比例
→ 更换页面布局
→ 在设计系统允许范围内小幅调整字号
→ 内容仍过载时拆页并返回内容确认
```

**Forbidden — force fit**：不得通过无限缩小字体、负行距、裁掉文字或把正文压进图片来强行容纳内容。

---

## 6. 通过条件

- 所有文字对象完整可见，没有超出页面或模块边界。
- 文字与图片没有非预期交叠；设计性覆盖具有足够对比度。
- 正文按语义分段，标题、正文、图注和来源层级明确。
- SVG 预览与最终 PPTX 的文字换行没有造成内容丢失或遮挡。
- `production/layout-review.md` 对每页记录 `passed`，失败页完成修复并重新检查。
