# SVG 预处理与预览规范

## 1. 读取时机

最终 SVG 质量检查通过后、执行 `finalize_svg.py` 前读取本文。

本阶段从 `svg_output/` 生成自包含的 `svg_final/` 预览副本。它不改变页面决策，也不拥有 PPTX 导出输入。

## 2. 输入与输出

| 类型 | 路径 | 所有权 |
|---|---|---|
| 原始页面 | `<project>/svg_output/*.svg` | 项目唯一可编辑页面源 |
| 本地素材 | SVG 引用的图片与图标 | 上游素材阶段维护 |
| 预览页面 | `<project>/svg_final/*.svg` | Finalizer 每次重新生成的派生物 |

**Hard rule**：原生 PPTX 转换始终读取 `svg_output/`。`svg_final/` 只用于自包含预览、诊断或手动查看，不得作为发布转换源。

## 3. 执行命令

正常项目执行：

```text
python scripts/finalize_svg.py <project_path>
```

统一后端入口默认包含该步骤：

```text
python scripts/run_backend.py <project_path> --title <title> --changed-pages <pages>
```

`--dry-run` 和 `--only` 只用于定位单项预处理问题。发布流程执行完整步骤，不用局部命令代替完整 Finalizer。

## 4. 固定处理顺序

| 顺序 | 处理 | 结果 |
|---|---|---|
| 1 | 复制 `svg_output/` | 重新建立 `svg_final/` 工作副本 |
| 2 | 展开图标与静态同文档 `<use>` | 将可解析引用变为实际 SVG 元素 |
| 3 | 对齐并嵌入图片 | 按 `slice`/`meet` 处理显示区域，并将支持的本地图片嵌入 SVG |
| 4 | 展平 `tspan` | 生成对特殊渲染器更稳定的独立文本节点 |

图片的对齐与嵌入必须在同一次处理内完成，避免先裁剪再重复序列化造成位置偏差。支持的位图与 SVG 素材可变为 Base64 数据；无法安全嵌入的格式必须保留明确引用或阻断，不得悄悄丢失。

## 5. 通过条件

- `svg_final/` 存在，且页面文件清单与 `svg_output/` 一致。
- 每个预览 SVG 可以解析，页面画布和页码未改变。
- 图标、图片与文字预处理没有未解决错误。
- 预览与源 SVG 的可见内容一致；允许的差异仅来自引用展开、图片嵌入和文本展平。

没有图片或图标的页面可以正常通过，不得把“处理数量为零”误判为失败。

## 6. 失败处理

| 失败 | 处理 |
|---|---|
| 图片或图标找不到 | 修复素材路径或 SVG 引用，重新运行质量检查与 Finalizer |
| 图片无法读取或编码 | 更换为受支持文件，更新素材记录后重跑 |
| XML 或文本展平失败 | 修复 `svg_output/` 中的源结构后重跑 |
| 预览与源页面不一致 | 停止转换，定位发生偏差的预处理步骤 |

不得手工修补 `svg_final/` 后继续导出。任何修复都回到 `svg_output/` 或其上游所有者，再重新生成派生预览。
